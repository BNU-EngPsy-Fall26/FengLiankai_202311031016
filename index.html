从"感觉"里，把"判断"分出来

传统心理物理学用"阈限"描述感知，可被试一开始猜测，阈限就随奖惩办法漂移。 信号检测论换了问法：感觉得到多少是辨别力， 愿不愿意说"有"是反应偏向——这两件事必须分开测量。

d′ 辨别力 两个感觉分布隔得多远
β / C 判断标准 把标准放在哪一处
ROC 感受性曲线 标准变、辨别力不变

两个分布重叠的部分，正是判断会出错的地方。

先定义清楚：四种结果

每一次判断，现实只有两种状态（有信号 / 无信号），被试也只会给两种回答（有 / 无）， 交叉起来就是四种结果。信号检测论的全部指标都从这张 2×2 表长出来。

现实 ＼ 回答 被试报告
报告"有信号" 报告"无信号"
实际 有信号 SN 击中 Hit P(Y / SN) 信号来了，说"有" 漏报 Miss P(N / SN) 信号来了，说"没有"
无信号 N 虚报 False Alarm P(Y / N) 只是噪音，却说"有" 正确拒斥 Correct Rejection P(N / N) 只是噪音，说"没有"

行和恒为 1：P(Hit) + P(Miss) = 1，P(FA) + P(CR) = 1。 注意：只看"正确率"会掩盖偏向—— 一个全说"有"的人正确率恰等于信号先验概率，但 d′ = 0。

历史对比

每玩完一轮，这一轮的难度设定、实测辨别力 d′ 与 判断标准 C 都会自动存下来。 在这里把几轮摆在一起看：d′ 稳不稳、C 有没有随先验概率或奖励设置移动。

怎么读这张表

  • 难度设定 / 理论 d′：开局时你选的那一档难度。它是"题目本身有多难"， 与你发挥得好不好无关——这是对照组。
  • 实测 d′：由这一轮实际的 P(Hit) 与 P(FA) 反推出来，是你真实分辨能力的估计。 试次越少波动越大，20 试次时差个零点几很正常。
  • 实测 C：你的判断标准。C 越负越倾向报"有"（松），越正越倾向报"无"（紧）。 改先验概率或奖励矩阵再玩一轮，动的主要是它，而不是 d′。
  • 偏差：实测 d′ 减去该轮的理论 d′。接近 0 说明发挥正常； 若明显为负，先看是不是难度设高了，再看是不是这一轮运气差。

理论要点

1两个分布：N 与 SN

同一刺激反复呈现，感觉量并不会稳定在同一个值，而是形成一个连续分布。 只有噪音时形成 N 分布；噪音上叠加了信号则形成 SN 分布。SN 分布的均值总是大于 N 分布。 两者的距离反映信号强度与感受性的共同结果——这就是 d′。

d′ = Z(hit) − Z(fa) = μ(SN) − μ(N) 等方差正态假设下成立

2判断标准 C 与 β

被试把感觉量与一条主观标准比较，超过就说"有"。标准的两种刻度： β 是标准处两分布纵坐标之比（似然比，比值刻度，不对称）； C 是标准到两分布中点的距离（距离刻度，可跨条件直接比较）。

C = −Z(hit) + Z(fa)2 β = O(SN)O(N) = ed′·C

拖动上面的 C 滑块，β 会同步变化：C = 0 时 β = 1（无偏）；C 越正 β 越大（越保守）。

3ROC 曲线：标准变，辨别力不变

同一条 ROC 曲线上的每个点，都对应同一个 d′ 但不同的 C。 从右下到左上，标准由宽松变严格。曲线离对角线越远，d′ 越大； 对角线本身（P(hit) = P(fa)）意味着 d′ = 0，即完全无法分辨。

AUC = Φd′√2 Z(hit) = d′ + Z(fa)

把坐标换成 Z 分数，ROC 会变成一条直线，斜率为 1、截距为 d′。 若实测斜率明显小于 1，说明 SN 分布方差大于 N 分布，d′ 的等方差前提不成立。

4什么在推动判断标准

先验概率越高（信号越常见），越应当降低标准多报告"有"； 漏报代价越高（如雷达漏掉敌机），也应当放松标准。两者共同决定最优 β：

βopt = P(N)P(S) × VCR − VFAVHit − VMiss P = 概率　V = 支付值　CR/FA/Hit/Miss 为四种结果

游戏里可以亲自验证：把先验概率从 0.5 调到 0.9，再玩一轮， 看自己的 C 是否随之下移。

计算约定与边界处理

  • 正态假设：N 与 SN 均为正态分布且方差相等（齐性）。这是 d′ = Z(hit) − Z(fa) 成立的前提。
  • 极端比例修正：若命中率或虚报率为 0 / 1，Z 值发散。本平台采用 k + 0.5N + 1 修正，并在结算页标注。
  • β 与 C 的关系：严格满足 β = ed′·C，故 β 同时受 d′ 与 C 影响，不能单独用来判断感受性。
  • AUC：等方差模型下 AUC = Φd′√2，取值 (0.5, 1)；d′ = 0 时恰为 0.5。
  • 正确率的陷阱：百分正确率 = P(hit) + P(CR)2 会随 C 偏离无偏点而下降，无法区分"分辨得好"和"偏向得当"。
